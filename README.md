# FaceMorph

An open-source, client-side 3D explorer of facial geometry and geographic reference data.

The first implementation is an **illustrative geometry prototype**. Geographic controls and demo deformations do not represent measured differences between populations. A scientifically valid atlas requires appropriately licensed, matched 3D reference meshes and documented statistical estimates.
